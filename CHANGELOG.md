# 📝 Changelog

Todas as mudanças notáveis neste projeto serão documentadas neste arquivo.

O formato é baseado em [Keep a Changelog](https://keepachangelog.com/pt-BR/1.0.0/),
e este projeto adere ao [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2025-09-08

### ✨ Adicionado
- **Nova Interface Moderna**: Redesign completo da home page
- **Bootstrap 5.3.0**: Atualização para a versão mais recente
- **Font Awesome 6.4.0**: Ícones vetoriais modernos
- **Dashboard Interativo**: Estatísticas em tempo real
- **Design Responsivo**: Interface adaptada para mobile
- **Navegação Organizada**: Menu estruturado por categorias
- **Animações Suaves**: Efeitos de hover e transições
- **Cards de Estatísticas**: Visão rápida dos KPIs principais

### 🔄 Modificado
- **Layout Principal**: Reestruturação completa do layout
- **Sistema de Navegação**: Menu dropdown organizado por módulos
- **Tipografia**: Fonte Inter para melhor legibilidade
- **Cores e Gradientes**: Paleta de cores moderna
- **Home Controller**: Adicionadas estatísticas do dashboard

### 🐛 Corrigido
- **Versão do Ruby**: Atualizada no Gemfile (3.1.0 → 3.4.5)
- **Dependências**: Instalação do pkg-config e sqlite3-dev
- **Sintaxe do Layout**: Corrigidos erros de sintaxe no ERB

### 🗑️ Removido
- **Bootstrap 3**: Removida versão antiga
- **Layout Antigo**: Removido design legacy
- **Estilos Obsoletos**: Limpeza de CSS não utilizado

## [1.0.0] - Data Anterior

### ✨ Adicionado
- **Sistema de Autenticação**: Devise para login/registro
- **Módulos Base**: Vendas, Produtos, Clientes, Funcionários
- **Banco de Dados**: Estrutura completa com migrações
- **Gráficos**: Integração com Chartkick/Google Charts
- **CRUD Completo**: Para todas as entidades principais

### 📋 Módulos Incluídos
- Gestão de Produtos
- Cadastro de Clientes
- Sistema de Vendas
- Controle Financeiro
- Recursos Humanos
- Gestão de Estoque
- Relatórios Básicos
